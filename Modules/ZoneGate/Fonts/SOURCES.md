# Polices supplémentaires

Les onze polices ajoutées proviennent du dépôt officiel https://github.com/google/fonts au commit `1edf95b4328bc5997ca93d2c0c7205272ec7347f`, dossier `ofl/<famille>`. Chaque fichier Regular est livré avec sa licence OFL originale, sans modification du fichier de police.

Familles : Marcellus, Cormorant SC, Almendra, Amiri, Tajawal, Rajdhani, Rye, Forum, Barlow Condensed, Philosopher, Caudex.

Les fichiers sont des TrueType statiques. Les lettres françaises, ligatures œ/æ et apostrophe typographique sont vérifiées par `Tests/fonts_test.py`. Exception connue : Rye ne contient pas le Ÿ majuscule ; choisir une autre police pour les titres utilisant ce caractère.

Suggestions : Marcellus pour les sanctuaires et thèmes de jade ; Cormorant SC pour les ambiances de cristal ; Almendra et Caudex pour les légendes ; Amiri ou Tajawal pour les thèmes du Moyen-Orient ; Barlow Condensed pour la survie ; Rajdhani pour la science-fiction ; Rye pour le western ; Forum pour les ruines ; Philosopher pour le voyage.

Le choix d'Amiri ou Tajawal ne constitue pas une prise en charge de la composition arabe par le client : l'aperçu et les tests portent sur le texte latin et français.
